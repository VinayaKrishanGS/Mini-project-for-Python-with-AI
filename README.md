# Student Performance Analytics System

**Student:** VinayaKrishnan G.S

## Project Title
Student Performance Analytics System

## Objective
Summarizes student marks from a CSV file: totals, averages, grades, pass/fail and top performers.

## Technologies Used
Python, NumPy, Pandas, Google Colab, GitHub

## Dataset Description
`students.csv`: 18 students with marks in five subjects (out of 100) and attendance.

## Implementation
Loads the CSV with Pandas, calculates totals with NumPy, uses functions and loops for averages, grades and pass/fail, then prints the analysis.

## Key Features
- Total and average marks per student
- Grades A to F
- Pass/fail (pass mark: 50)
- Highest, lowest and average performance
- Subject-wise analysis
- Top 3 students

## Output
Results are printed to the console.

## Final Outcome
The program runs without errors and produces a clear report from the CSV file.

## Challenges & Learning
Handling file names with and without `.csv`. Learned to load data with Pandas and calculate with NumPy.
